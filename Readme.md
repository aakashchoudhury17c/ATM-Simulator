# ATM Simulator

A simple console-based ATM Simulator built with Java. This project demonstrates basic Java programming concepts such as methods, loops, switch statements, conditional statements, and user input handling.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Prevent withdrawal when balance is insufficient
- Validate invalid amounts
- Menu-driven interface

## Technologies Used

- Java
- Scanner
- VS Code

## How It Works

The program starts with an initial balance of **₹1000**.

Users can choose from the following options:

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

The program continues running until the user selects the Exit option.

## How to Run

### 1. Compile the program

```bash
javac ATM_Simulator.java
```

### 2. Run the program

```bash
java ATM_Simulator
```

## Example

```text
=== ATM Simulator ===

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

Enter your choice: 1

Current Balance: ₹1000.00
```
